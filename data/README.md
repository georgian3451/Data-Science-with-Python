# Data

| Path | What | Source |
|---|---|---|
| `raw/titanic.csv` | Titanic passenger manifest, 891 rows x 12 cols (Weeks 1, 2, 4) | [datasciencedojo/datasets](https://github.com/datasciencedojo/datasets) (originally Kaggle) |
| `raw/wine.csv` | UCI Wine Recognition data, 178 rows x 13 chemical features + `cultivar` (Week 3) | scikit-learn `load_wine()` (UCI ML Repository); regenerated by `week3_clustering/clustering_analysis.py` |
| `raw/fashion-mnist/*.gz` | Fashion-MNIST, 60k train + 10k test 28x28 grayscale images, 10 clothing classes (Week 5), ~30 MB | [zalandoresearch/fashion-mnist](https://github.com/zalandoresearch/fashion-mnist); also via `python scripts/download_data.py` |
| `processed/titanic_cleaned.csv` | Output of Week 1 cleaning: 891 x 16, 0 missing values | generated by `week1_data_cleaning/02_clean_preprocess.py` |
| `processed/data_dictionary.csv` | Column-by-column description of the cleaned file | hand-written |
| `processed/sample_cleaned_head10.csv` | First 10 rows of the cleaned file | generated |
